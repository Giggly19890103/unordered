=简介

:idprefix: intro_ \
:cpp: C++

哈希表是非常受欢迎的计算机数据结构，几乎所有编程语言都以某种形式提供该结构。尽管其他关联数据结构（例如在C++中使用的`std::set`和`std::map`所依赖的红黑树）对于插入和查找操作具有对数级时间复杂度，但哈希表若配置得当，这些操作的平均时间复杂度可降至常数级别——并且通常速度快得多。\

* **闭寻址容器**完全符合C++无序关联容器的规范要求，在标准接口的技术限制下拥有市面上最快的实现之一。
* **开放式寻址结构**通过微调标准接口（牺牲部分兼容性）实现了远超传统容器的效率提升（实测典型场景提速两倍有余），其核心是依赖更高效的数据结构与算法。提供两种具体实现：**扁平容器**（至速版本）和**节点容器**形式的解决方案——后者以轻微性能损耗为代价，确保重哈希时容器元素的指针稳定性。
* 最后，**并发容器**专为高性能多线程场景设计并实现，其接口与常规C++容器截然不同。该库同时提供了平面和基于节点两种变体实现。

Boost.Unordered中的所有集合和映射的实例化方式分别类似于`std::unordered*set`和`std::unordered*map`：

----

    // concurrent_flat_map and concurrent_node_map

在无序关联式容器中存储对象需要同时提供键值相等函数和哈希函数。标准容器默认的函数对象支持若干基础类型，包括整型、浮点型、指针类型以及标准字符串。由于Boost.Unordered采用了链接:../../../../container_hash/index.html[boost::hash^]，因此还额外支持标准容器等其他类型。若需使用这些方法不支持的任意类型，您必须扩展Boost.Hash以兼容该类型，或使用自定义的相等谓词和哈希函数。具体操作详见
xref:hash_equality.adoc#hash_equality[相等谓词与哈希函数] 小节说明。\
